# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email <security@titusai.io> with a description of the issue, the affected
version, and steps to reproduce if you have them. You will get an
acknowledgement within three business days and a status update as the fix
progresses. If you would like to encrypt the report, ask for a key in your
first message.

We ask that you give us a reasonable window to ship a fix before disclosing
publicly; we will credit you in the release notes unless you would rather we
did not.

## Supported versions

KimmyDB is pre-1.0. Security fixes go into the latest `0.MINOR` line only;
upgrade to the newest release to receive them.

# ADR-238: the mutation rows, and the test that kills each

> **Removed by [ADR-251](decisions.md#adr-251--binary-_id-subtypes) (0.53.0).** The rows below that name `mixed_roll_tests`, `migrate_v5_tests`, the frozen `legacy_key` form, the token and cursor conversions or the vector chunk-id adoption and legacy reads cite tests that no longer exist; they are kept as the record of 0.51.0 and 0.52.0.

This is the table [ADR-238](decisions.md) refers to. Each row is a change to the source that must make a test fail: it was applied to the post-format text, run against the targeted tests under a timeout, and reset. A row that is recorded as *equivalent* cannot be killed, and says why. The rows are grouped by the piece of the change they guard.

## The comparator and the number key

Run on a `git archive 23c42a25` export, own target dir, `nice -n 10`, a 900 s timeout per suite, each row an exact-match patch applied once against the whole `cargo test -p kimmy-core --lib` suite (284 tests at the baseline, green), then reverted. Every one of the 60 rows applied unchanged: no re-pointing was needed (the numerics files are byte-identical to `decimal128-numfix`). **59 killed, 1 equivalent.** Full test lists: `mutate_final.log`.

## The wire conversions, the digest and the key inventory

Every row was applied to a `git archive` export of the merged head, run against the targeted suites under a timeout, and restored. Nine rows once planted a stored key as a `LegacyKey` through `from_wire`, which no longer exists, so they now plant the same fault the type still allows: the stored bytes wrapped as a `DocId::Binary` key. One row, `answer-cap-on-stored-bytes`, is behaviourally equivalent (`excluded_digest`'s own cap counts the wire bytes of a superset of the same keys) and is held only by the source guard.
